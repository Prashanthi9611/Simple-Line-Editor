
# Simple Line Editor in C

## Project Description
A simple command-line text editor developed using
the C programming language.

Users can create, insert, delete, edit, search,
replace and save text documents.

## Technologies Used
- C Programming
- VS Code
- GCC Compiler
- Dynamic Memory Allocation

## Data Structure
Dynamic Array of Strings.

## Core Features
1. Insert Line
2. Delete Line
3. Display Document
4. Save and Load File

## Bonus Features
1. Search
2. Find and Replace
3. Undo Last Action
4. Line Count / Word Count
